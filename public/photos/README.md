# Photo slots

Drop real club photos in this folder and reference them from the JSON content files
with a root-relative path, e.g. `"image": "/photos/season-opener.jpg"`.

Suggested sizes:
- Player portraits — 4:5 portrait, ~800 × 1000 px
- Gallery photos — 4:3 landscape, ~1200 × 900 px (the featured gallery item is 16:10)
- Home court / about photo — 5:4 landscape, ~1200 × 960 px

Keep each file under ~500 KB. Until a photo is added, the site renders a designed
court-line placeholder in its place, so nothing looks broken.
